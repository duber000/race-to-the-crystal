# Music Assets

Audio files served by the web server at `/static/assets/music/` and loaded by
`static/audio_manager.js`.

## Files

1. `techno.mp3` — background music loop (low key techno), toggled with `M`
2. `generator_0_hum.wav` … `generator_3_hum.wav` — per-generator ambient hums,
   played while a generator is active and stopped when it is captured

Both file sets are royalty-free / self-produced assets committed to this
repository. Replace them in place if you want different audio; no code
changes are needed as long as the filenames stay the same.

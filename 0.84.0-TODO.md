## High-value

- [x] **`server/http_handler.kuki:503-510`** — `any_to_int()` is a literal re-implementation of `cast.ToInt` (handles int/int64/float64/string/bool; even returns the identical `"cannot convert to int"` error string). Delete the helper; call `cast.ToInt(val)` at the 3 call sites (lines 478, 499, 500).
- [x] **`client/ai/ai_client.kuki:124-130`** — `castInt(m, key)` checks `v is int` on JSON-decoded data. JSON numbers arrive as `float64`, so the check always fails and it silently returns 0 — a latent bug. → `cast.ToIntOr(v, 0)` (handles float64). Call sites: lines 93, 201.
- [x] **`client/ai/http_ai_client.kuki:245-247,251-253`** — same guarded-int pattern in `TryAutoStart` → `cast.ToIntOr(cur_any, 0)` / `cast.ToIntOr(min_any, 0)`.
- [x] **`server/auth.kuki:18-23` + `mercure_publisher.kuki:106-110`** — `base64url_encode`/`base64url_decode` wrappers around the *padded* `encpkg.Base64URLEncode/Decode`. These encode JWT header/payload/signature, and JWT requires **unpadded** base64url — the current code is technically wrong, not just hand-rolled. → switch to the new `encoding.Base64URLNoPadEncode` / `encoding.Base64URLNoPadDecodeOr(s, empty list of byte)` (RawURLEncoding semantics) in one pass; `Base64URLDecodeOr` also deletes the decode wrapper.
- [x] **6 membership loops → `slice.Contains`** (the codebase already uses it correctly in game/player.kuki and game/board.kuki — these are stragglers):
  - `game/ai_actions.kuki:157-162` (`ValidateMove`) → `if not slice.Contains(valid_moves, dest)`
  - `game/ai_actions.kuki:217-222` (`ValidateDeploy`, TOKEN_HEALTH_VALUES)
  - `game/ai_actions.kuki:245-250` (`ValidateDeploy`, valid_positions)
  - `game/token.kuki:23-28` (`NewToken`, TOKEN_HEALTH_VALUES)
  - `game/movement.kuki:86-90` (`is_valid_move`) → `return slice.Contains(moves, dest)`
  - `server/action_validation.kuki:118-122` (`ValidateDeploy`)
- [x] **5 random picks → `random.Choice` / `random.ChoiceOr`** (new):
  - `game/game_state.kuki:327` — `effects[random.Int(0, len(effects))]` → `random.Choice of enums.CrystalEffect(effects)`
  - `game/ai_strategy.kuki:83-84` (`choose_random`) → `random.Choice of ActionResponse(actions)`
